# Inventory Management System – MySQL

## About the Project

This is a demo Inventory Management System developed as a hands-on SQL learning project. It demonstrates how MySQL can be used to manage product details, categories, suppliers and stock information.

## Database Structure

The project includes three main tables:

- **Categories:** Stores product category details.
- **Suppliers:** Stores supplier information.
- **Products:** Stores product details, pricing and available stock.

The tables are connected using primary keys and foreign key relationships.

## Key Features

- Create and manage inventory records.
- Add, update, retrieve and delete product information.
- Filter and sort products based on price and stock quantity.
- Calculate total inventory value and average product price.
- Generate category-wise product summaries.
- Identify low-stock products using a SQL view.
- Update stock quantities using a stored procedure.
- Track stock changes using SQL triggers.

## SQL Concepts Used

- Database and table creation
- Primary keys and foreign keys
- INSERT, SELECT, UPDATE and DELETE
- WHERE, ORDER BY, GROUP BY and HAVING
- Aggregate functions
- Joins and subqueries
- Views
- Stored procedures
- Triggers
- String and numeric functions

## Technologies Used

- MySQL
- SQL
- MySQL Workbench

## How to Run

1. Install MySQL Server and MySQL Workbench.
2. Open the SQL script in MySQL Workbench.
3. Execute the script to create the database, tables and sample records.
4. Run the queries to explore the inventory operations and reports.
